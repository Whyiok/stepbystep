# StepByStep

Прототип платформы пошаговых инструкций. В этой версии каталог, создание инструкций, чек-листы, заметки и прогресс работают в браузере через `localStorage`. Серверная регистрация, публикация и аналитика пока не подключены; пароли не сохраняются. Общая шапка закреплена сверху и имеет одинаковую высоту на страницах; SVG-иконки встроены без зависимости от сторонних библиотек.

## Запуск

Нужен Python 3.8+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

Откройте `http://127.0.0.1:5000`. Также можно запустить напрямую: `python app.py`.

## Основные страницы

- `index.html` — каталог и поиск демо-инструкций;
- `instruction.html?id=1` — пошаговое прохождение и сохранение прогресса;
- `create.html` — создание локальной инструкции;
- `dashboard.html` — список созданных в этом браузере инструкций;
- `login.html` и `register.html` — интерфейсные формы без серверной авторизации.

## Хранение данных

Пользовательские инструкции, заметки, комментарии и отметки прогресса хранятся только в локальном хранилище браузера. Очистка данных сайта удалит эти записи. Файл `data/stepbystep.db` оставлен из исходного архива, но текущий прототип его не использует.

## Структура

```text
app.py                  локальный Flask-сервер
run.py                  запуск сервера и браузера
base.html               общий layout (Jinja): <head>, шапка, футер, подключение css/js
partials/header.html    шапка сайта (подсветка пункта — через active_page)
partials/icons.html     SVG-спрайт иконок
index.html              каталог
login.html              вход (демо)
register.html           регистрация (демо)
dashboard.html          личный кабинет
create.html             создание инструкции
instruction.html        прохождение инструкции
css/                    стили и тема
js/                     данные и клиентская логика
```

## Шаблоны (Jinja)

Каждая страница наследует `base.html` и переопределяет блоки `title`, `styles`, `content`, `footer_text` и `scripts`. Пункт меню подсвечивается переменной, которую страница задаёт в начале файла: `{% set active_page = 'catalog' %}` (значения: `catalog`, `dashboard`, `create`, `login`, `register`). Ссылки и подключаемые файлы строятся через `url_for('page', name='login.html')` и `url_for('asset', folder='css', filename='style.css')`.
